# Contributing to the Manchester AI Guild

Thank you for contributing to the Manchester AI Guild.

## Scope

This organization hosts both public-facing project work and private member-only operations. Public repositories should remain clear, useful, and representative of the Guild mission. Private repositories should be used only for operational planning and member coordination.

## Contribution expectations

- keep public work respectful, accurate, and useful
- prefer issues and pull requests for structured discussion
- do not post private member, operational, or security-sensitive details in public repos
- keep detailed charter and governance discussion in the private operations repo unless a public version is explicitly approved

## Before opening a change

- review existing issues and milestones first
- ensure the work aligns with the Guild mission and practical AI adoption focus
- keep the scope relevant to delivery, governance, member support, or ecosystem collaboration

## Pull requests

- keep pull requests focused and easy to review
- include context and rationale in the description
- request review when a change affects governance, public messaging, or security-sensitive work
- do not include secrets or credentials
